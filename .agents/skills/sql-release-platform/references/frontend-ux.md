## 视觉语言

保持当前个人运维控制台风格：

- 使用带轻微层次的暖白背景，不使用单调纯白底。
- 正文使用深色，主操作使用克制青绿色，警告使用琥珀色，危险操作使用红色。
- 中文字体要有辨识度但保持清晰，不要做成千篇一律的后台模板。
- 桌面端居中并限制最大宽度，不要让页面铺满超宽屏。
- 卡片使用圆角、浅边框、克制阴影、英文小标题和清晰层级。
- 动效只用于有意义的反馈，例如页面进入、执行按钮光效、加载和状态变化。
- 发布执行台与所有 MD5 页面保持同一视觉体系。

不得把 SQL 发布执行台拉得过宽；不得因为错误的网格或宽度规则，让本地 MD5 页面中文文字变成一字一行。

## 发布执行台

除非用户明确要求调整布局，否则保持模块顺序：

1. 页面标题和 MD5 入口。
2. 上传目录。
3. 环境配置。
4. 最突出的脚本生成区域。
5. 操作输出。
6. 远程当前/历史日志。
7. 系统日志和操作日志。

上传和环境配置处于同一行时要上下对齐；改成上下排列时保持宽度和间距一致。

脚本生成是最高频功能。临时 SQL 与常规 SQL 分区展示，显示当前选中数量，支持一键选择临时 SQL 和一键清空，展示脚本修改时间，支持显示/隐藏及刷新脚本内容。

远程迁移 SQL 单独分区，并明确提示它使用当前环境中的迁移数据库连接。SSH 配置与迁移数据库配置在视觉和文案上必须区分，避免用户误把 Linux 登录密码当成数据库密码。

常规 SQL 区提供自定义配置入口，明确显示配置归属的当前环境、SQL 文件、远程 PG 地址和端口、数据库、账户和独立日志。密码输入支持显示/隐藏，但自定义卡片不得展示密码。新增成功后立即显示为可选卡片；删除前必须确认，并说明只删除配置、不删除远程 SQL 文件和已有日志。

“执行脚本”是最强操作按钮，但必须保持文字清晰，并提供禁用/加载状态。动效不能遮盖按钮是否已经成功点击。

## MD5 页面

`/md5` 只负责清晰选择本地或远程扫描。`/md5/local` 和 `/md5/remote` 的页面外壳、宽度、标题、卡片间距和表格风格与发布执行台一致。

多个结果路径使用不同但协调的标题颜色。完整展示路径名称、文件数量、总大小、MD5、文件大小、时间和时间来源。长表格限制在约 10 行高度，更多文件通过滚动查看。

本地 MD5 结果区提供清晰的排序工具栏。允许按文件路径、文件大小和文件时间切换；大小和时间默认使用更适合排查的降序，并支持反向切换。排序状态要显示当前字段和方向，每个路径分组独立排序，切换排序时不得重新计算 MD5。

本地 MD5 页面必须准确区分：

- 手工绝对路径由运行 FastAPI 的机器读取，保存后刷新仍然存在。
- 浏览器选择目录受浏览器权限控制，通常只能获得目录名称，不能获得完整绝对路径。

不能把浏览器目录选择描述成“上传文件”。Chrome 权限弹窗中的“查看和复制文件”是浏览器固定文案，页面应说明系统只读取文件计算 MD5，不把文件复制到其他位置。

## 弹窗与反馈

重要操作使用弹窗确认或展示结果：

- 上传目录：无论成功还是失败都弹窗。
- 清理远程目录：请求前确认，展示环境和完整路径，完成后展示结果。
- 删除环境配置：删除前确认。
- 生成和执行：显示明确加载状态和最终结果；如果现有交互已经使用弹窗，则继续保持。

通过禁用当前按钮或使用请求中标志避免重复提交，并在 `finally` 中恢复按钮。即使用户关闭弹窗，“操作输出”区域也要保留可用于排查的信息。

绿色只用于确认成功，红色用于确认失败和危险操作，琥珀色用于等待和警告，中性灰/青色用于普通信息。日志包含 `COMMIT` 时使用绿色成功标签，包含 `ROLLBACK` 时使用红色失败标签，两者都没有时使用黄色“请检查”标签；`ROLLBACK` 优先且匹配不区分大小写。日志结果标签放在文件名后面，不要推到最右侧。

## 响应式约束

- 包含长路径的 Grid/Flex 子元素设置 `min-width: 0`。
- 路径和 MD5 允许换行或内部滚动，不能撑宽整个页面。
- 在合理的平板和手机断点把多列布局改成单列。
- 按钮保持可点击尺寸，不能出现单个巨大按钮把卡片高度撑坏。
- 标题必须横向可读，不能缩成一字一行。
- CSS 修改后同时测试桌面宽度和窄屏宽度。

## 修改检查清单

1. 修改 ID 前检查已有 CSS 选择器和 JavaScript 事件监听。
2. 保持后端接口地址、JSON 字段和页面 `fetch` 调用同步。
3. 确认每个按钮只有一个有效监听，并有加载、成功和失败反馈。
4. 确认弹窗可以关闭，不遗留上一次确认回调。
5. 确认待上传数量、SQL 选中数量、当前环境、脚本时间和日志范围正确更新。
6. 检查空数据、加载中、成功和失败状态。
7. 检查长路径、多日志、大量 MD5 文件和中文内容。
8. 在不改变业务功能的前提下测试桌面和移动端布局。
